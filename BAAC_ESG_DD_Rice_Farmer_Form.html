= – เฮกตาร์

1 เฮกตาร์ = 6.25 ไร่

คำอธิบายง่ายๆ ระดับความเสี่ยงของพื้นที่ (เลือกตามที่ตรงกับนาของเกษตรกรมากที่สุด)
  • พื้นที่เสี่ยงสูง — น้ำท่วมบ่อย หรือแล้งบ่อย หรือร้อนจัดจนผลผลิตเสียหายบ่อย (เช่น ทุ่งต่ำน้ำท่วมซ้ำ / นอกเขตชลประทานที่ขาดน้ำบ่อย) → เลือกข้อนี้
  • พื้นที่เสี่ยงปานกลาง — เคยมีน้ำท่วมหรือแล้งบ้าง แต่ไม่ทุกปี หรือมีชลประทานช่วยได้บางส่วน → เลือกข้อนี้
  • พื้นที่เสี่ยงต่ำ — น้ำท่วม/แล้งน้อย ดินและน้ำค่อนข้างมั่นคง หรืออยู่ในเขตชลประทานที่ดี → เลือกข้อนี้
  • ข้าวภาคกลาง (ค่าเริ่มต้น) — ใช้เมื่อไม่แน่ใจ หรือเป็นนาในที่ราบภาคกลางทั่วไป

ถ้าไม่แน่ใจ ให้ถามเกษตรกรว่า “ปีที่ผ่านมา น้ำท่วมหรือแล้งจนเสียหายบ่อยไหม?” แล้วเลือกตามคำตอบ

คำย่อที่พบบ่อย (อ่านง่าย)
  • TRIS = ประกันภัยข้าวของเกษตรกร (ช่วยชดเชยเมื่อผลผลิตเสียหายจากภัยธรรมชาติ)
  • NDS = ประกันภัยพิบัติแห่งชาติ (ความช่วยเหลือจากรัฐเมื่อเกิดภัยพิบัติรุนแรง)
  • AWD = ทำนาแบบเปียกสลับแห้ง (ขังน้ำสลับปล่อยให้ดินแห้ง เป็นรอบๆ ประหยัดน้ำ ลดก๊าซมีเทน)
  • DSR = หว่านข้าวแห้ง (หว่านเมล็ดลงดินโดยตรง ไม่ต้องเพาะกล้าและไม่ต้องขังน้ำตอนต้นฤดู)
  • LLL = ปรับระดับดินด้วยเลเซอร์ (ทำพื้นนาเรียบ น้ำกระจายสม่ำเสมอ)
  • SSNM = ใส่ปุ๋ยตามค่าดิน (ตรวจดินก่อน แล้วใส่ปุ๋ยเท่าที่จำเป็น)
  • IPM = จัดการศัตรูพืชแบบผสมผสาน (ใช้วิธีธรรมชาติร่วมด้วย เพื่อลดสารเคมี)
  • CAP = แผนปฏิบัติการแก้ไข (แผนที่เกษตรกรกับธนาคารตกลงว่าจะปรับปรุงอะไร เมื่อไหร่)

ก) ความสามารถในการรับมือและปรับตัวต่อความเสี่ยงทางกายภาพด้านสภาพภูมิอากาศ
1 ที่ตั้งทางภูมิศาสตร์และการป้องกันพื้นที่ –

นา/แปลงอยู่ที่ไหน และมีวิธีป้องกันน้ำท่วม ความร้อน ศัตรูพืชหรือไม่

0
โซนเสี่ยงสูง และไม่มีมาตรการปรับตัวใด ๆ
0.25
โซนเสี่ยงสูง แต่ใช้พันธุ์อายุสั้น
หรืออยู่โซนเสี่ยงปานกลางอย่างเดียว
0.5
โซนเสี่ยงปานกลาง + ใช้พันธุ์อายุสั้น
หรืออยู่โซนเสี่ยงต่ำ
0.75
โซนเสี่ยงปานกลาง + มีชลประทาน
+ ทำนาปรังได้
1.0
โซนเสี่ยงต่ำ + มีชลประทาน
+ ทำนาปรัง + ใช้พันธุ์อายุสั้น
จำง่าย: ยิ่งพื้นที่ปลอดภัย + มีน้ำชลประทาน + ใช้พันธุ์ดี = คะแนนสูงขึ้น
2 ความสามารถในการรับมือด้านการจัดหาน้ำ –

มีน้ำใช้พอหรือไม่ และใช้น้ำอย่างประหยัดหรือไม่ (สำคัญมากสำหรับข้าว)

0
ไม่มีวิธีประหยัดน้ำ และไม่มีแหล่งน้ำสำรอง
0.25
มีวิธีประหยัดน้ำอย่างน้อย 1 อย่าง
(ปรับระดับดิน / เปียกสลับแห้ง / หว่านแห้ง)
หรือมีบ่อบาดาล
0.5
มีชลประทานเข้าถึงได้
หรือมีมาตรการประหยัดน้ำหลายอย่าง
0.75
มีชลประทาน + ใช้วิธีประหยัดน้ำ
อย่างน้อย 1–2 อย่าง
1.0
มีชลประทาน + หลายวิธีประหยัดน้ำ
+ มีแหล่งกักเก็บน้ำสำรอง
จำง่าย: มีน้ำชลประทาน + ประหยัดน้ำ + มีน้ำสำรอง = คะแนนสูง
3 ความสามารถในการรับมือด้านการจัดหาพลังงาน –

ถ้าไฟฟ้าดับ ยังสูบน้ำเข้านา/แปลงได้หรือไม่

0
พึ่งไฟฟ้าอย่างเดียว ไม่มีปั๊มสำรอง
0.25
มีปั๊มสำรอง (น้ำมันหรือโซลาร์)
ประมาณ 1 ใน 4 ของที่ต้องใช้
0.5
มีปั๊มสำรองประมาณครึ่งหนึ่ง
ของกำลังที่ต้องใช้
0.75
มีปั๊มสำรองพอใช้ทั้งนา
(น้ำมันหรือโซลาร์)
1.0
ไม่ต้องสูบน้ำเลย (น้ำไหลเอง)
หรือใช้โซลาร์ทั้งหมด
จำง่าย: ยิ่งพึ่งไฟฟ้าโครงข่ายน้อย หรือใช้โซลาร์มาก = คะแนนสูง
4 ความสามารถในการรักษาความต่อเนื่องของห่วงโซ่อุปทาน –

ซื้อปุ๋ย เมล็ดพันธุ์ น้ำมันง่ายไหม และขายผลผลิตได้สะดวกไหม

0
ถนนเข้าถึงยาก และไม่มีของสำรอง
0.25
ถนนใช้ได้เฉพาะฤดูแล้ง
มีของสำรองบ้างเล็กน้อย
0.5
มีถนนใช้ได้ตลอดปี
+ กักเก็บของได้ประมาณครึ่งหนึ่ง
0.75
มีหลายเส้นทางใช้ได้ตลอดปี
+ มีที่เก็บของ/เก็บผลผลิต
1.0
ถนนดีหลายเส้นทาง
เข้าถึงตลาดหลายแห่งได้ง่าย
จำง่าย: ถนนดี + มีที่เก็บของ/ผลผลิต + ขายได้หลายที่ = คะแนนสูง
5 ระบบข้อมูลและการเตือนภัยล่วงหน้า –

รู้ข่าวอากาศ น้ำ และศัตรูพืชล่วงหน้าไหม

0
ไม่ได้รับข่าวเตือนภัยล่วงหน้า
0.25
ฟังข่าววิทยุ/ทีวี
และอยู่ในกลุ่มไลน์หมู่บ้าน/เจ้าหน้าที่
0.5
ได้รับแจ้งเตือนจากเจ้าหน้าที่
หรือแอปพยากรณ์อากาศเป็นประจำ
0.75
มีข้อมูลอากาศเฉพาะพื้นที่
และทันเวลา (agro-met)
1.0
ใช้ข้อมูลแบบจำลองอากาศ
วางแผนปลูกล่วงหน้า
จำง่าย: ยิ่งได้ข่าวเร็วและเฉพาะพื้นที่ = คะแนนสูง
6 การประกันภัยที่เพียงพอและการสนับสนุนเพื่อการฟื้นฟู –

มีประกันพืชผลหรือไม่ คุ้มครองมากแค่ไหน

0
ไม่มีประกันใด ๆ (รวม NDS)
0.25
มีสิทธิ์ประกันภัยพิบัติแห่งชาติ NDS (ความช่วยเหลือเมื่อเกิดภัยพิบัติร้ายแรง)
อย่างเดียว
0.5
มีประกันข้าว TRIS (ประกันภัยข้าวจากธนาคารเพื่อการเกษตรฯ / กรมการข้าว) ชั้น 1 หรือ ชั้น 2
(รวมกับ NDS)
0.75
มีประกันเพิ่มที่คุ้มครอง
ต้นทุนปัจจัยการผลิตเกือบทั้งหมด
1.0
มีประกันที่คุ้มครองรายได้
ที่เสียหายได้เกือบทั้งหมด
จำง่าย: มีแค่ NDS (ประกันภัยพิบัติแห่งชาติ) = 0.25 · มี TRIS (ประกันข้าว) = 0.5 · มีประกันครอบคลุมมากขึ้น = คะแนนสูงขึ้น
ข) ความสามารถในการรับมือของรายบุคคลต่อความเสี่ยงจากการเปลี่ยนผ่าน
7 การลดการปล่อยก๊าซเรือนกระจก (GHG) –

ทำนา/เกษตรแบบลดก๊าซมีเทนหรือไม่ (เช่น เปียกสลับแห้ง)

0
ทำนาแบบขังน้ำตลอด ไม่มีมาตรการลด GHG
0.25
เริ่มใช้วิธีลดน้ำขังบ้าง
แต่ยังไม่สม่ำเสมอ
0.5
ใช้วิธีเปียกสลับแห้ง AWD (Alternating Wetting and Drying – ขังน้ำสลับปล่อยให้ดินแห้งเป็นรอบ)
หรือหว่านแห้ง DSR (Direct Seeded Rice – หว่านเมล็ดลงดินแห้ง ไม่ต้องเพาะกล้า) เป็นหลัก
0.75
ใช้ AWD หรือ DSR
+ ปรับระดับดินด้วยเลเซอร์ LLL (Laser Land Leveling – ทำผิวดินเรียบสม่ำเสมอ)
1.0
ใช้ครบ: ปรับระดับดิน + เปียกสลับแห้ง
+ ใส่ปุ๋ยตามค่าวิเคราะห์ดิน SSNM (Site-Specific Nutrient Management)
จำง่าย: ยิ่งลดการขังน้ำต่อเนื่อง + ใช้ปุ๋ยถูกต้อง = คะแนนสูง
8 พลังงานหมุนเวียน (น้ำหนัก×2) –

สูบน้ำ/ใช้เครื่องจักรด้วยไฟฟ้าหรือโซลาร์มากแค่ไหน

0
ใช้ปั๊มน้ำมันเป็นหลัก ไม่มีโซลาร์
0.25
ใช้ไฟฟ้าบ้านเป็นหลัก
(ไม่ใช้ปั๊มน้ำมันเป็นหลัก)
0.5
ใช้โซลาร์ประมาณครึ่งหนึ่ง
ของกำลังที่ต้องการ
0.75
ใช้โซลาร์ประมาณ 3 ใน 4
ของกำลังที่ต้องการ
1.0
ใช้โซลาร์ทั้งหมด
หรือไม่ต้องสูบน้ำเลย
จำง่าย: ยิ่งใช้โซลาร์มาก = คะแนนสูง (น้ำหนักสองเท่า)
9 ประสิทธิภาพการใช้ทรัพยากร –

ใช้น้ำ ปุ๋ย สารเคมี อย่างประหยัด และจัดการฟาง/เศษวัสดุดีไหม

0
ไม่มีมาตรการประหยัดน้ำ/ปุ๋ย/สารเคมี/จัดการฟาง
0.25
มีมาตรการอย่างน้อย 1 อย่าง
(ประหยัดน้ำ / ปุ๋ย / สารเคมี / จัดการฟาง)
0.5
มีมาตรการ 2 อย่าง
0.75
มีมาตรการ 3 อย่าง
1.0
ครบทั้ง 4 อย่าง:
ประหยัดน้ำ + ใส่ปุ๋ยถูกวิธี + ลดสารเคมี + ไม่เผาฟาง
จำง่าย: ยิ่งทำหลายอย่าง (น้ำ ปุ๋ย สารเคมี ฟาง) = คะแนนสูง
10 ผลิตภัณฑ์ยั่งยืน / ใบรับรอง (น้ำหนัก×2) –

มีใบรับรองข้าว/ผลผลิตที่ยั่งยืนหรืออินทรีย์หรือไม่

0
ไม่มีใบรับรองและยังไม่เริ่มเตรียม
0.25
กำลังเตรียมเอกสาร
หรือสมัครใบรับรองอยู่
0.5
ผ่านการตรวจเบื้องต้น
หรือมีใบรับรองกลุ่ม/ชุมชน
0.75
มีใบรับรองมาตรฐาน
แต่ยังไม่ครบทุกแปลง
1.0
มีใบรับรองอย่างน้อย 1 ระบบ
(TAS / SRP / อินทรีย์ ฯลฯ)
จำง่าย: มีใบรับรองมาตรฐาน = คะแนนเต็ม (น้ำหนักสองเท่า)
ค) การบริหารความเสี่ยงด้านสิ่งแวดล้อมและสังคม
11 มลพิษและการปล่อยมลสาร (น้ำหนัก×2) –

ใช้สารเคมีถูกกฎหมายไหม ลดการใช้ไหม และไม่เผาตอซังไหม

0
ใช้สารเคมีไม่ถูกต้อง หรือเผาตอซังโดยไม่มีมาตรการอื่น
0.25
ใช้สารเคมีที่ขึ้นทะเบียนถูกต้อง
และจดบันทึกการใช้
0.5
+ ลดสารเคมีด้วยวิธีผสมผสาน IPM (Integrated Pest Management – ลดสารเคมี ใช้วิธีธรรมชาติร่วมด้วย)
หรือใส่ปุ๋ยตามค่าดิน SSNM (วิเคราะห์ดินก่อนใส่ปุ๋ย)
หรือไม่เผาตอซัง
0.75
ลดทั้งปุ๋ยและสารเคมี
หรือไม่เผา + มีมาตรการอื่น
1.0
